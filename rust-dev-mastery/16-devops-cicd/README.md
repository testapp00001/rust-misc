# Module 16: DevOps & CI/CD for Rust

Master the art of building, testing, deploying, and monitoring Rust applications in production.

## Lessons

| # | File | Topic |
|---|------|-------|
| 01 | `p01_github_actions.rs` | Workflow design, caching, matrix builds, artifact management |
| 02 | `p02_release_workflows.rs` | cargo-release, changelog generation, semantic versioning |
| 03 | `p03_cross_compilation.rs` | Cross-compiling targets, cross tool, musl, ARM, linkers |
| 04 | `p04_docker_patterns.rs` | Multi-stage builds, scratch images, cargo-chef, layer caching |
| 05 | `p05_monitoring_setup.rs` | Health checks, metrics, Prometheus, Grafana dashboards |
| 06 | `p06_deployment_strategies.rs` | Blue-green, canary, rolling updates, feature flags |
| 07 | `p07_artifact_management.rs` | Binary distribution, cargo install, GitHub releases |
| 08 | `p08_environment_management.rs` | dev/staging/prod configs, secret injection, validation |
| 09 | `p09_infrastructure_as_code.rs` | Terraform/Pulumi patterns, infrastructure idempotency |
| 10 | `p10_production_operations.rs` | Runbooks, on-call, incident response, SLOs/SLIs |

## Key Concepts

- **CI Pipelines**: Automated build, test, lint, and security scanning
- **Release Automation**: Version bumping, changelogs, artifact publishing
- **Cross-Compilation**: Building for multiple OS/architecture targets
- **Containerization**: Efficient Docker images for Rust binaries
- **Observability**: Metrics, health checks, structured logging
- **Deployment Patterns**: Safe rollout strategies for production
- **Infrastructure as Code**: Reproducible infrastructure management
