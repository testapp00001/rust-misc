# Module 20: Code Quality

Master Rust code quality tools, conventions, and practices for
maintainable, well-documented codebases.

## Lessons

| # | File | Topic |
|---|------|-------|
| 01 | `p01_clippy_mastery.rs` | Clippy lint groups, custom configuration, suppressing vs fixing |
| 02 | `p02_rustfmt_config.rs` | rustfmt.toml, formatting rules, import ordering |
| 03 | `p03_documentation_standards.rs` | Doc comment conventions, module docs, crate docs |
| 04 | `p04_code_review.rs` | Review checklist, common findings, review automation |
| 05 | `p05_refactoring_patterns.rs` | Extract function, extract trait, introduce newtype |
| 06 | `p06_technical_debt.rs` | Identifying debt, TODO/FIXME conventions, prioritization |
| 07 | `p07_naming_conventions.rs` | Rust naming conventions, type names, function names |
| 08 | `p08_comment_philosophy.rs` | When to comment, self-documenting code, API docs |
| 09 | `p09_module_organization.rs` | File structure, mod.rs vs named files, re-exports |
| 10 | `p10_code_metrics.rs` | Complexity metrics, cargo-deny, cargo-udeps, MSRV |

## Key Concepts

- **Clippy**: Catch common mistakes and improve idiomatic Rust
- **rustfmt**: Consistent code formatting
- **Documentation**: Rustdoc conventions and best practices
- **Code Review**: Systematic review practices
- **Refactoring**: Safe transformation patterns
