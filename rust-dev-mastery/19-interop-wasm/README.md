# Module 19: Interop & WebAssembly

Learn to integrate Rust with other languages and platforms through FFI,
WebAssembly, and plugin systems.

## Lessons

| # | File | Topic |
|---|------|-------|
| 01 | `p01_py03_basics.rs` | PyO3 setup, Python-Rust interop patterns |
| 02 | `p02_wasm_fundamentals.rs` | wasm-bindgen, wasm-pack, JS interop |
| 03 | `p03_wasm_optimization.rs` | wasm-opt, code size, performance |
| 04 | `p04_c_embedding.rs` | Embedding Rust in C/C++, cdylib, C API |
| 05 | `p05_plugin_systems.rs` | Dynamic loading, plugin traits, safe interfaces |
| 06 | `p06_cross_language_testing.rs` | Testing FFI boundaries, property-based FFI testing |
| 07 | `p07_abi_stability.rs` | repr(C), versioned APIs, ABI evolution |
| 08 | `p08_node_native_modules.rs` | napi-rs, Node.js native modules |
| 09 | `p09_uniffi_patterns.rs` | Mozilla UniFFI, multi-language bindings |
| 10 | `p10_embedding_patterns.rs` | Embedding Rust in other runtimes |

## Key Concepts

- **FFI**: Foreign Function Interface for C interop
- **WebAssembly**: Compile Rust to run in browsers and Node.js
- **Plugin Systems**: Dynamic loading and safe plugin interfaces
- **ABI Stability**: Ensuring binary compatibility across versions
