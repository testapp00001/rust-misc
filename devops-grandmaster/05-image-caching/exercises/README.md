# Module 05: Image Caching -- Exercises

## Overview

These exercises reinforce the core concepts from [Module 05: Image Caching](../README.md).
Complete them in order -- each builds on the previous one.

## Exercise List

| # | Name | Type | Time | Difficulty |
|---|------|------|------|------------|
| 01 | Layer Caching and Invalidation Cascading | Conceptual | 15 min | Easy |
| 02 | Fix the Dockerfile That Rebuilds Everything | Guided | 30 min | Easy-Medium |
| 03 | Optimize a CI Pipeline's Build Time | Independent | 30 min | Medium |
| 04 | BuildKit Cache Mounts for a Polyglot Project | Challenge | 45 min | Medium-Hard |
| 05 | Caching Strategy for a Multi-Service Application | Integration | 45 min | Hard |

## How to Use These Exercises

1. Read the exercise file completely before starting.
2. Try to solve it without looking at hints first.
3. Use the `<details>` hint sections only if you are stuck.
4. After completing an exercise, check your answer against the solution.
5. If your answer differs from the solution, that is fine -- understand *why* both approaches work.

## Prerequisites

- You have read the [Module 05 README](../README.md).
- You have Docker installed with BuildKit enabled (`DOCKER_BUILDKIT=1`).
- You have a text editor available.
- You have completed [Module 04: Multi-Stage Builds](../04-multi-stage-builds/).
