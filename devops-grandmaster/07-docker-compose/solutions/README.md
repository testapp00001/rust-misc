# Module 07: Docker Compose -- Solutions

## Overview

This directory contains reference solutions for the [Module 07 exercises](../exercises/).
Each solution includes the complete answer, an explanation of *why* it works, and
common mistakes to avoid.

Read the solution only after attempting the exercise yourself. If your answer differs
from the solution, that is fine -- understand *why* both approaches work.

## Solution List

| # | Exercise | Key Concepts |
|---|----------|--------------|
| 01 | [Compose vs. Commands](solution-01.md) | Declarative vs. imperative, failure modes |
| 02 | [Build a Three-Service Stack](solution-02.md) | Services, networking, volumes, environment variables |
| 03 | [Hardening the Stack](solution-03.md) | Health checks, restart policies, resource limits |
| 04 | [Developer Paradise](solution-04.md) | Override files, hot reload, debug tools, seed data |
| 05 | [Production-Mirror Architecture](solution-05.md) | Network isolation, reverse proxy, multi-environment |

## How to Use These Solutions

1. Attempt the exercise first.
2. Compare your answer to the solution.
3. Read the "Why This Works" section to understand the reasoning.
4. Read the "Common Mistakes" section to avoid pitfalls.
5. If your approach differs, evaluate both -- there is often more than one valid way.
