# Module 07: Docker Compose -- Exercises

## Overview

These exercises reinforce the core concepts from [Module 07: Docker Compose](../README.md).
Complete them in order -- each builds on the previous one.

## Exercise List

| # | Name | Type | Time | Difficulty |
|---|------|------|------|------------|
| 01 | Compose vs. Commands: The Real Tradeoffs | Conceptual | 15 min | Easy |
| 02 | Build a Three-Service Stack | Guided | 30 min | Easy-Medium |
| 03 | Hardening the Stack | Independent | 30 min | Medium |
| 04 | Developer Paradise: Hot-Reload and Test DBs | Challenge | 45 min | Medium-Hard |
| 05 | Production-Mirror Architecture | Integration | 45 min | Hard |

## How to Use These Exercises

1. Read the exercise file completely before starting.
2. Try to solve it without looking at hints first.
3. Use the `<details>` hint sections only if you are stuck.
4. After completing an exercise, check your answer against the solution.
5. If your answer differs from the solution, that is fine -- understand *why* both approaches work.

## Prerequisites

- You have read the [Module 07 README](../README.md).
- You have Docker and Docker Compose V2 installed.
- You have a text editor available.
- You have completed [Module 06: Container Registries](../06-container-registries/) (recommended).
