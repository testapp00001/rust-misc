# Module 51: Network Security -- Exercises

## Overview
This exercise set walks you through the critical concepts and hands-on skills required to secure modern network infrastructure. Starting from understanding how flat networks enable lateral movement, you will progress through firewall rule authoring, production VPC design, security auditing, and finally zero-trust segmentation for containerized microservices. Each exercise builds on the previous one, reinforcing defense-in-depth principles and practical tooling with iptables, UFW, cloud security groups, VPNs, and network monitoring.

## Prerequisites
- Completion of Modules 1-50 (especially container and Kubernetes modules)
- Basic understanding of TCP/IP, subnets, and routing
- Familiarity with Linux command-line tools
- Access to a Linux environment (VM, cloud instance, or WSL)
- Understanding of YAML and basic infrastructure-as-code concepts

## How to Use These Exercises
1. Read the exercise file completely before starting any tasks.
2. Attempt each part on your own before checking the hint toggles.
3. Write your answers in a separate file or notebook for later comparison with the solutions.
4. For design exercises, draw diagrams using ASCII art or a tool like draw.io.
5. Time yourself to build real-world decision-making speed.
6. After completing an exercise, review the corresponding solution file to compare approaches and catch gaps.
