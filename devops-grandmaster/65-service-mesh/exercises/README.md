# Module 65: Service Mesh -- Exercises

## Overview

These exercises reinforce the concepts from the [Module 65 README](../README.md), covering service mesh architecture, Istio and Linkerd, mTLS, traffic management, observability, and production service mesh deployment.

## Exercise List

| # | Name | Type | Time | Difficulty |
|---|------|------|------|------------|
| 01 | Service Mesh Concepts | Conceptual | 20 min | Easy |
| 02 | mTLS Configuration | Guided | 30 min | Easy-Medium |
| 03 | Traffic Management | Independent | 35 min | Medium |
| 04 | Observability and Debugging | Challenge | 45 min | Medium-Hard |
| 05 | Production Service Mesh Deployment | Integration | 60 min | Hard |

## How to Use These Exercises

1. Read the exercise file carefully before starting
2. Attempt each part on your own before checking the hints
3. Use `kubectl` commands to verify your answers if you have a cluster
4. Check your work against the success criteria
5. Review the solution after completing the exercise, even if you got it right

## Prerequisites

- Basic understanding of Kubernetes (pods, services, deployments)
- Familiarity with networking concepts (TCP, TLS, HTTP)
- Read the [Module 65 README](../README.md)
