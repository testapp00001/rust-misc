# Module 20: Reverse Proxy — Exercises

These exercises progress from conceptual understanding to production-grade API gateway configuration.

| Exercise | Type | Topic |
|----------|------|-------|
| 01 | Conceptual | Reverse proxy vs forward proxy vs load balancer |
| 02 | Guided | Nginx reverse proxy with SSL termination |
| 03 | Independent | Traefik with Docker auto-discovery |
| 04 | Challenge | Path-based routing for microservices |
| 05 | Integration | API gateway with rate limiting and authentication |

## How to Use These Exercises

1. Read the objective and instructions carefully.
2. Attempt the exercise before looking at hints.
3. Check your work against the success criteria.
4. Only then consult the solution in `../solutions/`.
5. If you got it wrong, understand *why* before moving on.

## Prerequisites

- Docker and Docker Compose installed
- Basic understanding of HTTP (methods, headers, status codes)
- Familiarity with YAML syntax
- A text editor
