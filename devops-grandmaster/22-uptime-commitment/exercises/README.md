# Module 22: Uptime Commitment -- Exercises

Welcome to the exercises for Module 22. These exercises cover SLA, SLO, and SLI
definitions, availability targets, and error budget management.

## Exercises

| # | Title | Type | Focus |
|---|-------|------|-------|
| 01 | Calculate Downtime for Availability Targets | Conceptual | Translating availability percentages into real downtime |
| 02 | Define SLIs and SLOs for a Web Application | Guided | Selecting meaningful service level indicators and objectives |
| 03 | Create an Error Budget Policy | Independent | Designing a policy that governs what happens when budgets are spent |
| 04 | Balance Reliability and Velocity with SLOs | Challenge | Setting SLOs that avoid over-engineering while meeting user expectations |
| 05 | Build an SLO Dashboard with Prometheus and Grafana | Integration | Instrumenting real metrics and visualizing error budgets |

## Prerequisites

- Basic understanding of monitoring and observability concepts
- Familiarity with web application architecture
- For exercise 05: a running Kubernetes cluster with Prometheus and Grafana

## How to Use These Exercises

1. Work through the exercises in order -- they build on each other.
2. Attempt each exercise before looking at the hints.
3. Check your work against the success criteria listed in each exercise.
4. Solutions are available in the `../solutions/` directory.
