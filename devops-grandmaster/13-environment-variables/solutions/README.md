## How to Use These Solutions

1. Attempt each exercise before looking at the solution.
2. Compare your answer with the solution -- focus on *why* the solution works, not just *what* it contains.
3. If your answer differs, that is fine. Multiple valid approaches exist for most exercises.
4. Pay attention to the "Common Mistakes" sections -- they highlight errors that are easy to make and hard to debug.
