# Module 13: Environment Variables -- Exercises

## Overview

These exercises reinforce the core concepts from [Module 13: Environment Variables](../README.md).
Complete them in order -- each builds on the previous one.

## Exercise List

| # | Name | Type | Time | Difficulty |
|---|------|------|------|------------|
| 01 | The 12-Factor Config Philosophy | Conceptual | 15 min | Easy |
| 02 | Externalize Hardcoded Configuration | Guided | 30 min | Easy-Medium |
| 03 | Environment-Specific Configuration | Independent | 30 min | Medium |
| 04 | Env Var Validation and Defaults | Challenge | 45 min | Medium-Hard |
| 05 | Docker Compose and Kubernetes ConfigMaps | Integration | 45 min | Hard |

## How to Use These Exercises

1. Read the exercise file completely before starting.
2. Try to solve it without looking at hints first.
3. Use the `<details>` hint sections only if you are stuck.
4. After completing an exercise, check your answer against the solution.
5. If your answer differs from the solution, that is fine -- understand *why* both approaches work.

## Prerequisites

- You have read the [Module 13 README](../README.md).
- Docker Engine and Docker Compose installed.
- A text editor for writing YAML, Dockerfile, and shell scripts.
- `curl` for testing HTTP endpoints.
- (Exercise 05) A local Kubernetes cluster (minikube, kind, or Docker Desktop).

## Getting Help

If you get stuck:
- Re-read the relevant section of the module notes.
- Check `docker --help` and `docker compose --help` documentation.
- Look at the hint sections (hidden behind `<details>` tags).
- As a last resort, review the solution file -- but try to understand *why*
  the solution works, not just copy it.
