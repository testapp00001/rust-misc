# Module 24: When to Use Kubernetes -- Exercises

## Overview

These exercises reinforce the core concepts from [Module 24: When to Use Kubernetes](../README.md).
Complete them in order -- each builds on the previous one.

## Exercise List

| # | Name | Type | Time | Difficulty |
|---|------|------|------|------------|
| 01 | When Kubernetes Is (and Isn't) the Answer | Conceptual | 20 min | Easy |
| 02 | Pick the Right Orchestrator for Each App | Guided | 35 min | Easy-Medium |
| 03 | Build Your Organization's Decision Framework | Independent | 40 min | Medium |
| 04 | Kubernetes vs Alternatives: The Real Cost | Challenge | 50 min | Medium-Hard |
| 05 | Docker Compose to Kubernetes Migration Plan | Integration | 60 min | Hard |

## How to Use These Exercises

1. Read the exercise file completely before starting.
2. Try to solve it without looking at hints first.
3. Use the `<details>` hint sections only if you are stuck.
4. After completing an exercise, check your answer against the solution.
5. If your answer differs from the solution, that is fine -- understand *why* both approaches work.

## Prerequisites

- You have read the [Module 24 README](../README.md).
- You have read the [Module 24 Cheatsheet](../cheatsheet.md).
- You understand basic container concepts (Docker, Docker Compose).
- No Kubernetes cluster is required for these exercises (they focus on decision-making).
