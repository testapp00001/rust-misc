# Module 23: Graceful Shutdown -- Exercises

## Overview

These exercises reinforce the core concepts from [Module 23: Graceful Shutdown](../README.md).
Complete them in order -- each builds on the previous one.

## Exercise List

| # | Name | Type | Time | Difficulty |
|---|------|------|------|------------|
| 01 | The Container Shutdown Lifecycle | Conceptual | 20 min | Easy |
| 02 | Implement a Graceful Shutdown Handler | Guided | 30 min | Easy-Medium |
| 03 | Configure Kubernetes Shutdown Policies | Independent | 40 min | Medium |
| 04 | Database Connections During Shutdown | Challenge | 45 min | Medium-Hard |
| 05 | Zero-Downtime Deployment Design | Integration | 60 min | Hard |

## How to Use These Exercises

1. Read the exercise file completely before starting.
2. Try to solve it without looking at hints first.
3. Use the `<details>` hint sections only if you are stuck.
4. After completing an exercise, check your answer against the solution.
5. If your answer differs from the solution, that is fine -- understand *why* both approaches work.

## Prerequisites

- You have read the [Module 23 README](../README.md).
- You understand the difference between SIGTERM and SIGKILL.
- You have a text editor or terminal available.
- For exercises 03-05, basic familiarity with Kubernetes and Docker Compose is helpful.
