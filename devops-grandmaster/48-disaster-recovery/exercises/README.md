# Module 48: Disaster Recovery -- Exercises

These exercises build your ability to design, implement, and validate disaster recovery strategies. You will work through RPO/RTO analysis, failover automation, DR drills, and multi-region architectures.

## Exercise List

| # | Name | Type | Time | Difficulty |
|---|------|------|------|------------|
| 01 | RPO and RTO Analysis | Conceptual | 15 min | Easy |
| 02 | Failover Procedure Design | Guided | 30 min | Easy-Medium |
| 03 | Automated Failover Implementation | Independent | 30 min | Medium |
| 04 | Disaster Recovery Drill | Challenge | 45 min | Medium-Hard |
| 05 | Multi-Region DR Architecture | Integration | 45 min | Hard |

## How to Use These Exercises

1. Start with Exercise 01 and work through them in order.
2. Attempt each exercise before looking at the corresponding solution.
3. Use the hints only when stuck -- they are designed to guide, not give away the answer.
4. Check your work against the Success Criteria before moving on.

## Prerequisites

- Completed Module 48 README
- PostgreSQL 14+ with streaming replication configured
- Familiarity with Patroni, etcd, and distributed consensus
- Understanding of RPO and RTO concepts
- Access to cloud infrastructure (AWS, GCP, or Azure) for multi-region exercises
