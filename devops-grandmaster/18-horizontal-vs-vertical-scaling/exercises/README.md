# Module 18: Horizontal vs Vertical Scaling -- Exercises

## Overview

These exercises reinforce the core concepts from [Module 18: Horizontal vs Vertical Scaling](../README.md).
Complete them in order -- each builds on the previous one.

## Exercise List

| # | Name | Type | Time | Difficulty |
|---|------|------|------|------------|
| 01 | Scaling Trade-Offs | Conceptual | 15 min | Easy |
| 02 | Component Scaling Classification | Guided | 30 min | Easy-Medium |
| 03 | Multi-Tier Scaling Strategy | Independent | 30 min | Medium |
| 04 | Cost-Optimal Scaling Analysis | Challenge | 45 min | Medium-Hard |
| 05 | Horizontal Scaling with Docker Compose | Integration | 45 min | Hard |

## How to Use These Exercises

1. Read the exercise file completely before starting.
2. Try to solve it without looking at hints first.
3. Use the `<details>` hint sections only if you are stuck.
4. After completing an exercise, check your answer against the solution.
5. If your answer differs from the solution, that is fine -- understand *why* both approaches work.

## Prerequisites

- You have read the [Module 18 README](../README.md).
- You understand the difference between stateless and stateful applications.
- You have Docker and Docker Compose installed (for exercises 04 and 05).
- You have completed [Module 07: Docker Compose](../../07-docker-compose/) (for exercise 05).
