# Module 19: Load Balancing -- Exercises

## Overview

These exercises build your understanding of load balancing from foundational
concepts through production-grade multi-layer architectures. Work through them
in order; each one builds on skills from the previous.

| Exercise | Title | Type | Estimated Time |
|----------|-------|------|----------------|
| 01 | Load Balancing Algorithms | Conceptual | 30 min |
| 02 | Nginx as a Load Balancer | Guided | 45 min |
| 03 | Health-Check-Aware Load Balancing | Independent | 60 min |
| 04 | Compare Algorithms Under Load | Challenge | 90 min |
| 05 | Multi-Layer Load Balancing Architecture | Integration | 120 min |

## Prerequisites

- Docker and Docker Compose installed
- Basic familiarity with HTTP and networking concepts
- A terminal and text editor
- (Exercises 04-05) A load-testing tool such as `hey`, `wrk`, or `k6`

## How to Use

1. Read the exercise markdown file.
2. Follow the instructions step by step.
3. Check your work against the success criteria.
4. Only look at the hints if you are stuck for more than 10 minutes.
5. Compare your result with the corresponding solution in `../solutions/`.

## Getting Help

If you are stuck:

- Re-read the relevant section of the module notes.
- Use `docker logs <container>` to inspect behaviour.
- Check the hints inside each exercise (collapsed by default).
- Consult the solution file as a last resort.
