# Module 28: Services & Networking -- Exercises

## Overview

These exercises reinforce the core concepts from [Module 28: Services & Networking](../README.md).
Complete them in order -- each builds on the previous one.

## Exercise List

| # | Name | Type | Time | Difficulty |
|---|------|------|------|------------|
| 01 | ClusterIP vs NodePort vs LoadBalancer | Conceptual | 20 min | Easy |
| 02 | Create Services and Test Connectivity | Guided | 30 min | Easy-Medium |
| 03 | Service Discovery Using DNS | Independent | 30 min | Medium |
| 04 | Service Topology for Microservices | Challenge | 45 min | Medium-Hard |
| 05 | Expose Services with LoadBalancer and Ingress | Integration | 45 min | Hard |

## How to Use These Exercises

1. Read the exercise file completely before starting.
2. Try to solve it without looking at hints first.
3. Use the `<details>` hint sections only if you are stuck.
4. After completing an exercise, check your answer against the solution.
5. If your answer differs from the solution, that is fine -- understand *why* both approaches work.

## Prerequisites

- You have read the [Module 28 README](../README.md).
- You have a running Kubernetes cluster (minikube, kind, k3s, or a cloud cluster).
- You have `kubectl` installed and configured.
- You understand Pod lifecycle concepts from [Module 26](../26-pods-and-containers/).
- You understand Deployments and ReplicaSets from [Module 27](../27-deployments-and-replicasets/).
