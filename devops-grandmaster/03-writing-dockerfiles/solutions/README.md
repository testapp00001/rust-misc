# Module 03: Writing Dockerfiles -- Solutions

## Overview

This directory contains detailed solutions for all exercises in [Module 03: Writing Dockerfiles](../exercises/README.md).

Each solution includes:
- The complete answer
- An explanation of *why* the approach works
- Common mistakes to avoid
- References to the relevant sections of the [Module 03 README](../README.md)

## How to Use These Solutions

1. Attempt each exercise before looking at the solution.
2. Compare your answer to the solution -- focus on *differences*, not just correctness.
3. If your answer is different but equally valid, that is fine. Understand the trade-offs.
4. Read the "Common Mistakes" sections even if you got the exercise right.
