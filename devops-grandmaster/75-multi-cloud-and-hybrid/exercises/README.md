# Module 75: Multi-Cloud and Hybrid -- Exercises

Welcome to the exercises for Multi-Cloud and Hybrid cloud strategies. These
exercises progress from conceptual understanding to building a fully
cloud-agnostic application platform.

## Exercise Overview

| # | Title | Type | Difficulty |
|---|-------|------|------------|
| 1 | Multi-Cloud vs Hybrid Cloud Trade-Offs | Conceptual | Beginner |
| 2 | Abstract Cloud Services with Terraform | Guided | Intermediate |
| 3 | Implement Cross-Cloud Networking | Independent | Intermediate |
| 4 | Design a Multi-Cloud Disaster Recovery Strategy | Challenge | Advanced |
| 5 | Build a Cloud-Agnostic Application Platform | Integration | Expert |

## Prerequisites

- Basic understanding of at least one public cloud (AWS, Azure, or GCP)
- Familiarity with infrastructure-as-code concepts
- Terraform CLI installed (exercises 2, 3, 5)
- Docker installed (exercise 5)
- General networking knowledge (VPCs, subnets, routing)

## How to Use These Exercises

1. Start with exercise 01 and work sequentially.
2. Attempt each exercise before looking at the corresponding solution.
3. Use the hints only after genuine effort.
4. Exercises 1-3 can be completed in a few hours each.
5. Exercises 4-5 are multi-day efforts that synthesize multiple concepts.

## Key Themes

- **Avoiding vendor lock-in**: Design systems that can migrate between clouds.
- **Federation**: Unify identity, policy, and management across providers.
- **Multi-cloud strategies**: Use multiple clouds deliberately, not accidentally.
