# Module 02: Your First Container -- Exercises

## Overview

These exercises reinforce the core commands and concepts from [Module 02: Your First Container](../README.md).
Complete them in order -- each builds on the previous one.

## Exercise List

| # | Name | Type | Time | Difficulty |
|---|------|------|------|------------|
| 01 | What Happens When You Run a Container? | Conceptual | 15 min | Easy |
| 02 | Run, Inspect, Stop, Remove | Guided | 25 min | Easy |
| 03 | Manage a Multi-Container Application | Independent | 35 min | Medium |
| 04 | Debug a Misbehaving Container | Challenge | 30 min | Medium-Hard |
| 05 | Container Lifecycle Management Scenario | Integration | 45 min | Hard |

## How to Use These Exercises

1. Read the exercise file completely before starting.
2. Try to solve it without looking at hints first.
3. Use the `<details>` hint sections only if you are stuck.
4. After completing an exercise, check your answer against the solution.
5. If your answer differs from the solution, that is fine -- understand *why* both approaches work.

## Prerequisites

- You have read the [Module 02 README](../README.md).
- Docker is installed and running (`docker --version` succeeds).
- You can run containers without `sudo` (your user is in the `docker` group).
