# Module 02: Your First Container -- Solutions

## Overview

This directory contains detailed solutions for each exercise in [Module 02: Your First Container](../exercises/README.md).

**Important:** Try each exercise yourself before reading the solutions.
The learning happens in the struggle, not in the answer.

## Solution List

| # | Exercise | Key Concepts |
|---|----------|--------------|
| 01 | [What Happens When You Run a Container?](solution-01.md) | Docker run internals, image vs container, implicit options |
| 02 | [Run, Inspect, Stop, Remove](solution-02.md) | Container lifecycle commands, inspection, state persistence |
| 03 | [Manage a Multi-Container Application](solution-03.md) | Multiple containers, naming, exec, stats, ordered shutdown |
| 04 | [Debug a Misbehaving Container](solution-04.md) | Troubleshooting workflow, logs, inspect, exec debugging |
| 05 | [Container Lifecycle Management Scenario](solution-05.md) | Networks, sidecars, failure simulation, recovery, cleanup |

## How to Use These Solutions

1. Attempt the exercise first.
2. If you get stuck, re-read the hints in the exercise file.
3. Only then read the solution.
4. If your approach differs from the solution, compare the trade-offs.
5. Run the commands yourself -- do not just read them.
