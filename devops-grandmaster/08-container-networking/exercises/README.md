# Module 08: Container Networking -- Exercises

## Overview

These exercises build your understanding of Docker container networking from
conceptual foundations through production-grade network architecture design.
Complete them in order -- each builds on the previous one.

## Exercise List

| # | Name | Type | Time | Difficulty |
|---|------|------|------|------------|
| 01 | Bridge vs Host vs Overlay Networks | Conceptual | 20 min | Easy |
| 02 | Create Custom Networks and Connect Containers | Guided | 30 min | Easy-Medium |
| 03 | Debug a Networking Issue Between Containers | Independent | 45 min | Medium |
| 04 | Design a Network Topology for a Microservices App | Challenge | 60 min | Medium-Hard |
| 05 | Implement Network Segmentation for Security | Integration | 45 min | Hard |

## How to Use These Exercises

1. Work through them in order -- each builds on the previous one.
2. Read the objective and instructions carefully before starting.
3. Use the hints only after you have attempted the exercise yourself.
4. Check your work against the success criteria listed at the end of each exercise.
5. Compare your solution with the corresponding file in `../solutions/`.

## Prerequisites

- Docker Engine 24+ installed and running
- Docker Compose v2 installed
- Basic familiarity with `docker run` and `docker exec`
- A terminal and a text editor

## Getting Help

If you get stuck:

- Re-read the relevant section of the [module notes](../README.md).
- Check `docker network --help` and `docker run --network` documentation.
- Look at the hint sections (hidden behind `<details>` tags).
- Review the [cheatsheet](../cheatsheet.md) for quick command reference.
- As a last resort, review the solution file -- but try to understand *why*
  the solution works, not just copy it.
