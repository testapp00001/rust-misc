# Module 60: GitOps -- Exercises

## Overview

These exercises reinforce the core concepts from [Module 60: GitOps](../README.md).
Complete them in order -- each builds on the previous one.

## Exercise List

| # | Name | Type | Time | Difficulty |
|---|------|------|------|------------|
| 01 | Push vs Pull Deployment | Conceptual | 15 min | Easy |
| 02 | Set Up an ArgoCD Application | Guided | 30 min | Easy-Medium |
| 03 | Design a Multi-Environment GitOps Repo | Independent | 30 min | Medium |
| 04 | Handle Secrets and Drift Detection | Challenge | 45 min | Medium-Hard |
| 05 | GitOps with Canary Deployment | Integration | 45 min | Hard |

## How to Use These Exercises

1. Read the exercise file completely before starting.
2. Try to solve it without looking at hints first.
3. Use the `<details>` hint sections only if you are stuck.
4. After completing an exercise, check your answer against the solution.
5. If your answer differs from the solution, that is fine -- understand *why* both approaches work.

## Prerequisites

- You have read the [Module 60 README](../README.md).
- You have a text editor or terminal available.
- Basic understanding of Kubernetes, Git, and YAML.
- Familiarity with [Module 58](../58-blue-green-deployment/README.md) and [Module 59](../59-canary-deployment/README.md) is recommended.
