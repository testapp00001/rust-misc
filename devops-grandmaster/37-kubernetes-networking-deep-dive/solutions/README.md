## Using These Solutions

1. Attempt the exercise first. Solutions are meant for verification, not
   copy-paste.
2. If you are stuck, use the exercise hints before reading the solution.
3. After reading a solution, try to reproduce it from memory.
4. Focus on the "Why It Works" and "Common Mistakes" sections -- they build
   the intuition you need for real-world scenarios.
