# Module 01: Why Containers -- Exercises

## Overview

These exercises reinforce the core concepts from [Module 01: Why Containers Exist](../README.md).
Complete them in order -- each builds on the previous one.

## Exercise List

| # | Name | Type | Time | Difficulty |
|---|------|------|------|------------|
| 01 | The "It Works On My Machine" Autopsy | Conceptual | 15 min | Easy |
| 02 | Build a Reproducibility Problem, Then Fix It | Guided | 30 min | Easy-Medium |
| 03 | VM vs Container: Real Scenario Comparison | Independent | 30 min | Medium |
| 04 | Design a Containerization Strategy | Challenge | 45 min | Medium-Hard |
| 05 | From Broken Deployment to Containerized Pipeline | Integration | 45 min | Hard |

## How to Use These Exercises

1. Read the exercise file completely before starting.
2. Try to solve it without looking at hints first.
3. Use the `<details>` hint sections only if you are stuck.
4. After completing an exercise, check your answer against the solution.
5. If your answer differs from the solution, that is fine -- understand *why* both approaches work.

## Prerequisites

- You have read the [Module 01 README](../README.md).
- You have a text editor or terminal available.
- No Docker installation is required for these exercises (they focus on concepts).
