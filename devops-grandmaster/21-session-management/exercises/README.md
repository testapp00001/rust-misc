# Module 21: Session Management -- Exercises

## Overview

These exercises reinforce the core concepts from [Module 21: Session Management](../README.md).
Complete them in order -- each builds on the previous one.

## Exercise List

| # | Name | Type | Time | Difficulty |
|---|------|------|------|------------|
| 01 | Why Stateless Design Enables Horizontal Scaling | Conceptual | 20 min | Easy |
| 02 | Convert a Stateful App to Use Redis for Session Storage | Guided | 45 min | Medium |
| 03 | Implement JWT-Based Stateless Authentication | Independent | 45 min | Medium-Hard |
| 04 | Design Session Management for a Multi-Region Deployment | Challenge | 60 min | Hard |
| 05 | Sticky Sessions vs Shared State vs Stateless: A Comparison | Integration | 45 min | Medium |

## How to Use These Exercises

1. Read the exercise file completely before starting.
2. Try to solve it without looking at hints first.
3. Use the `<details>` hint sections only if you are stuck.
4. After completing an exercise, check your answer against the solution.
5. If your answer differs from the solution, that is fine -- understand *why* both approaches work.

## Prerequisites

- You have read the [Module 21 README](../README.md).
- You have a text editor or terminal available.
- Exercises 02 and 03 require Docker and Docker Compose installed.
- Exercise 04 and 05 are design exercises (no coding required).
