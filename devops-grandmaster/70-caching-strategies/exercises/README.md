# Module 70: Caching Strategies -- Exercises

## Overview
These exercises reinforce the core concepts from [Module 70: Caching Strategies](../README.md).
Complete them in order -- each builds on the previous one.

## Exercise List
| # | Name | Type | Time | Difficulty |
|---|------|------|------|------------|
| 01 | Cache Pattern Selection | Conceptual | 15 min | Easy |
| 02 | Cache-Aside with Redis | Guided | 30 min | Easy-Medium |
| 03 | Cache Stampede Prevention | Independent | 30 min | Medium |
| 04 | Multi-Layer Cache Architecture | Challenge | 45 min | Medium-Hard |
| 05 | Production Caching System | Integration | 45 min | Hard |

## How to Use These Exercises
1. Read the exercise file completely before starting.
2. Try to solve it without looking at hints first.
3. Use the `<details>` hint sections only if you are stuck.
4. After completing an exercise, check your answer against the solution.
5. If your answer differs from the solution, that is fine -- understand *why* both approaches work.

## Prerequisites
- You have read the [Module 70 README](../README.md).
- You have Redis installed (locally or via Docker).
- You understand HTTP caching headers (Cache-Control, ETag, Last-Modified).
- You are familiar with Python and basic data structures.
