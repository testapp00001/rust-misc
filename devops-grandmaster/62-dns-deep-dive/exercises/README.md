# Module 62: DNS Deep Dive -- Exercises

## Overview

These exercises reinforce the concepts from the [Module 62 README](../README.md), covering DNS record types, resolution flow, TTL configuration, failover strategies, and production DNS architecture.

## Exercise List

| # | Name | Type | Time | Difficulty |
|---|------|------|------|------------|
| 01 | DNS Record Types | Conceptual | 20 min | Easy |
| 02 | DNS Resolution Flow | Guided | 30 min | Easy-Medium |
| 03 | TTL Configuration | Independent | 35 min | Medium |
| 04 | DNS Failover Setup | Challenge | 45 min | Medium-Hard |
| 05 | Production DNS Architecture | Integration | 60 min | Hard |

## How to Use These Exercises

1. Read the exercise file carefully before starting
2. Attempt each part on your own before checking the hints
3. Use `dig`, `nslookup`, and `host` commands to verify your answers
4. Check your work against the success criteria
5. Review the solution after completing the exercise, even if you got it right

## Prerequisites

- Basic understanding of networking (IP addresses, ports, protocols)
- Familiarity with the command line
- Access to `dig` or `nslookup` commands
- Read the [Module 62 README](../README.md)
