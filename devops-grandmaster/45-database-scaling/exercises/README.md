# Module 45: Database Scaling -- Exercises

## Overview
Hands-on exercises to practice read replicas, connection pooling, and query optimization techniques covered in [Module 45: Database Scaling](../README.md).

## Exercise List
| # | Name | Type | Time | Difficulty |
|---|------|------|------|------------|
| 01 | Scaling Strategy Identification | Conceptual | 15 min | Easy |
| 02 | Read Replica Setup with ProxySQL | Guided | 30 min | Easy-Medium |
| 03 | Connection Pool Configuration | Independent | 30 min | Medium |
| 04 | Query Optimization Audit | Challenge | 45 min | Medium-Hard |
| 05 | End-to-End Scaling Architecture | Integration | 45 min | Hard |

## How to Use These Exercises
1. Read the module README first to understand the concepts
2. Start with Exercise 01 and work sequentially
3. Attempt each exercise before looking at hints
4. Check your work against the success criteria
5. Review the solution even if you got it right -- there may be alternative approaches

## Prerequisites
- Completed Module 45 README
- PostgreSQL 14+ installed
- Docker and Docker Compose available
- Basic SQL proficiency
- Familiarity with Linux command line
