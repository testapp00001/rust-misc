# Module 72: Multi-Host Orchestration -- Exercises

## Overview

These exercises cover Docker Swarm, HashiCorp Nomad, and orchestrator comparison. Work through them after completing the [module lesson](../README.md).

## Exercise List

| # | Name | Type | Time | Difficulty |
|---|------|------|------|------------|
| 01 | Swarm vs Nomad vs Kubernetes | Conceptual | 15 min | Easy |
| 02 | Docker Swarm Stack Deployment | Guided | 30 min | Easy-Medium |
| 03 | Nomad Job Specification | Independent | 40 min | Medium |
| 04 | Multi-Host Networking and Failover | Challenge | 45 min | Medium-Hard |
| 05 | Orchestrator Migration Plan | Integration | 60 min | Hard |

## How to Use These Exercises

1. Read the module lesson (README.md) first.
2. Start with Exercise 01 to verify conceptual understanding.
3. Work through exercises in order -- each builds on the previous.
4. Attempt each exercise before looking at the hints.
5. Check your work against the solutions only after completing an exercise.

## Prerequisites

- Docker installed with Swarm mode available (or Docker-in-Docker)
- Basic understanding of containers and Docker Compose
- Familiarity with YAML and HCL syntax
- (For exercises 03-05) Nomad binary installed or access to Nomad documentation
