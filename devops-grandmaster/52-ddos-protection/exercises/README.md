# Module 52: DDoS Protection -- Exercises

## Overview
These exercises build practical skills in defending against Distributed Denial of Service (DDoS) attacks. You will classify attack types from real-world traffic patterns, implement multi-layer rate limiting in Nginx, design comprehensive defense architectures, practice emergency incident response under simulated attack conditions, and integrate DDoS-aware auto-scaling with circuit breakers and cost controls. By the end, you will be able to protect production systems against volumetric, protocol, and application-layer attacks while maintaining service availability and controlling infrastructure costs.

## Prerequisites
- Understanding of OSI model layers (L3, L4, L7)
- Familiarity with Nginx configuration syntax
- Basic knowledge of TCP/IP networking (SYN, ACK, connection state)
- Experience with Kubernetes concepts (pods, services, HPA)
- Understanding of HTTP request/response lifecycle
- Familiarity with cloud infrastructure concepts (load balancers, CDNs)
- Basic knowledge of monitoring and alerting systems

## How to Use These Exercises
1. Start with Exercise 01 to establish foundational knowledge of DDoS attack classification.
2. Work through each exercise in order -- later exercises build on concepts from earlier ones.
3. Attempt each exercise before looking at the corresponding solution file.
4. Use the hints provided in each exercise only when you are truly stuck.
5. Verify your work against the Success Criteria listed at the end of each exercise.
6. Review the "What You Should Understand" section to confirm your learning.
7. Time yourself to build the speed needed for real incident response scenarios.
