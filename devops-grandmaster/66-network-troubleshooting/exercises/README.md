# Module 66: Network Troubleshooting -- Exercises

## Overview

These exercises reinforce the concepts from the [Module 66 README](../README.md), covering tcpdump, traceroute, packet analysis, network diagnostics, and production troubleshooting workflows.

## Exercise List

| # | Name | Type | Time | Difficulty |
|---|------|------|------|------------|
| 01 | Network Diagnostic Tools | Conceptual | 20 min | Easy |
| 02 | tcpdump Fundamentals | Guided | 30 min | Easy-Medium |
| 03 | Traceroute and Path Analysis | Independent | 35 min | Medium |
| 04 | Packet Analysis with Wireshark | Challenge | 45 min | Medium-Hard |
| 05 | Production Network Troubleshooting | Integration | 60 min | Hard |

## How to Use These Exercises

1. Read the exercise file carefully before starting
2. Attempt each part on your own before checking the hints
3. Use actual commands on a test environment when possible
4. Check your work against the success criteria
5. Review the solution after completing the exercise, even if you got it right

## Prerequisites

- Basic understanding of TCP/IP networking (IP, TCP, UDP, HTTP)
- Familiarity with the Linux command line
- Access to a Linux machine with tcpdump installed
- Read the [Module 66 README](../README.md)
