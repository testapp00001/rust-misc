# Module 64: CDN and Edge -- Solutions

## Overview

This directory contains reference solutions for all five exercises in Module 64.

**Important**: These solutions are learning aids, not the only correct approach.
Compare your work against them, understand the reasoning, and adapt patterns to your
own production context.

## Solution Map

| # | Title | Key Concepts Demonstrated |
|---|-------|--------------------------|
| 01 | CDN Architecture and Edge Computing | Request flow diagrams, origin shields, edge compute trade-offs |
| 02 | Configure CloudFront for a Web Application | OAC, cache behaviors, SPA error handling, Terraform |
