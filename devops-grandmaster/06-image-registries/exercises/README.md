# Module 06: Image Registries -- Exercises

## Overview

These exercises reinforce the core concepts from [Module 06: Image Registries](../README.md).
Complete them in order -- each builds on the previous one.

## Exercise List

| # | Name | Type | Time | Difficulty |
|---|------|------|------|------------|
| 01 | Registry Architecture and Tag Strategies | Conceptual | 20 min | Easy |
| 02 | Push an Image to Docker Hub and Pull from Another Machine | Guided | 30 min | Easy-Medium |
| 03 | Set Up a Private Registry with TLS and Authentication | Independent | 45 min | Medium |
| 04 | Implement a Tag Strategy for a CI/CD Pipeline | Challenge | 45 min | Medium-Hard |
| 05 | Design a Registry Strategy for a Multi-Team Organization | Integration | 60 min | Hard |

## How to Use These Exercises

1. Read the exercise file completely before starting.
2. Try to solve it without looking at hints first.
3. Use the `<details>` hint sections only if you are stuck.
4. After completing an exercise, check your answer against the solution.
5. If your answer differs from the solution, that is fine -- understand *why* both approaches work.

## Prerequisites

- You have read the [Module 06 README](../README.md).
- You have Docker installed and running.
- You have a terminal available.
- For Exercise 02, you need a Docker Hub account (free at https://hub.docker.com).
- For Exercises 03-05, you need `openssl` and `htpasswd` installed.
