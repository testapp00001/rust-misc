## How to Use These Solutions

1. **Attempt the exercise first.** The solutions are here to check your work,
   not to replace the learning process.
2. **Compare approaches.** If your answer differs from the solution, that is
   fine. Focus on understanding *why* each approach works.
3. **Read the "Common Mistakes" sections.** These are lessons learned from
   real-world experience -- they save you from making the same errors.
4. **Review the "Why This Works" sections.** Understanding the reasoning
   behind a solution is more valuable than memorizing the solution itself.
