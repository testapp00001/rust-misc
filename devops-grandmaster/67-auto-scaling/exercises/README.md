# Module 67: Auto-Scaling -- Exercises

## Overview

These exercises reinforce the core concepts from [Module 67: Auto-Scaling](../README.md).
Complete them in order -- each builds on the previous one.

## Exercise List

| # | Name | Type | Time | Difficulty |
|---|------|------|------|------------|
| 01 | HPA vs VPA vs Cluster Autoscaler Decision Framework | Conceptual | 15 min | Easy |
| 02 | Writing an HPA with Custom Metrics and Behavior Policies | Guided | 30 min | Easy-Medium |
| 03 | Multi-Tier Auto-Scaling Strategy Design | Independent | 30-45 min | Medium |
| 04 | Debugging a Flapping HPA | Challenge | 45 min | Medium-Hard |
| 05 | Production-Grade Auto-Scaling System | Integration | 45-60 min | Hard |

## How to Use These Exercises

1. Read the exercise file completely before starting.
2. Try to solve it without looking at hints first.
3. Use the `<details>` hint sections only if you are stuck.
4. After completing an exercise, check your answer against the solution.
5. If your answer differs from the solution, that is fine -- understand *why* both approaches work.

## Prerequisites

- You have read the [Module 67 README](../README.md).
- You have a Kubernetes cluster with `metrics-server` installed (or `minikube`/`kind` for local testing).
- You have `kubectl` configured and can create resources.
- You understand basic Kubernetes concepts: Deployments, Services, Pods, resource requests/limits.
- (Exercises 04-05) You have Prometheus and Prometheus Adapter installed, or can install them during the exercise.
