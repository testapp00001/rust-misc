# Module 43: SLO Monitoring -- Exercises

## Overview

These exercises build practical skills in Service Level Objective (SLO) monitoring,
error budget management, burn rate alerting, and deployment gating policies.

You will work with real-world patterns drawn from the Google SRE handbook and
production observability stacks built on Prometheus and Grafana.

## Prerequisites

- Familiarity with Prometheus (PromQL) basics
- Understanding of what an SLO is (target availability percentage)
- Basic Grafana dashboard concepts
- Command-line comfort (bash)

## Exercises

| # | Title | Type | Focus |
|---|-------|------|-------|
| 01 | Error Budget Calculation | Conceptual | Math behind SLO targets and error budgets |
| 02 | Burn Rate Alerts in Prometheus | Guided | PromQL queries that detect fast-burning budgets |
| 03 | SLO Dashboard with Error Budget Visualization | Independent | Grafana dashboard panels for SLO tracking |
| 04 | Multi-Window Burn Rate Alerts | Challenge | 1h / 6h / 30d window alerting strategy |
| 05 | Error Budget Policy for Deployment Gating | Integration | Policy design that connects budgets to actions |

## How to Use These Exercises

1. Read the exercise file completely before starting.
2. Attempt the exercise without looking at the solution.
3. Check your work against the corresponding solution in `../solutions/`.
4. If stuck, use the hints -- but try first without them.
