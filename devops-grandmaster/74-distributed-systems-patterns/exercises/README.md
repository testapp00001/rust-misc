# Module 74: Distributed Systems Patterns -- Exercises

## Overview

These exercises cover the CAP theorem, consensus algorithms, eventual consistency, the Saga pattern, idempotency, circuit breakers, and retry strategies. Work through them after completing the [module lesson](../README.md).

## Exercise List

| # | Name | Type | Time | Difficulty |
|---|------|------|------|------------|
| 01 | CAP Theorem and PACELC | Conceptual | 15 min | Easy |
| 02 | Idempotent API Design | Guided | 30 min | Easy-Medium |
| 03 | Circuit Breaker Implementation | Independent | 40 min | Medium |
| 04 | Saga Pattern for Distributed Transactions | Challenge | 45 min | Medium-Hard |
| 05 | Resilient Microservice Architecture | Integration | 60 min | Hard |

## How to Use These Exercises

1. Read the module lesson (README.md) first.
2. Start with Exercise 01 to verify conceptual understanding.
3. Work through exercises in order -- each builds on the previous.
4. Attempt each exercise before looking at the hints.
5. Check your work against the solutions only after completing an exercise.

## Prerequisites

- Understanding of distributed systems concepts (networking, replication, failure modes)
- Python 3.x for code-based exercises
- Familiarity with HTTP APIs and JSON
