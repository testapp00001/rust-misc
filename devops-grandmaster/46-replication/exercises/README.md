# Module 46: Replication -- Exercises

These exercises build your ability to design, configure, and troubleshoot database replication topologies. You will work through master-slave setups, multi-master conflict resolution, replication lag analysis, and cross-region architectures.

## Exercise List

| # | Name | Type | Time | Difficulty |
|---|------|------|------|------------|
| 01 | Replication Topology Design | Conceptual | 15 min | Easy |
| 02 | Master-Slave Setup | Guided | 30 min | Easy-Medium |
| 03 | Multi-Master Conflict Resolution | Independent | 30 min | Medium |
| 04 | Replication Lag Analysis and Mitigation | Challenge | 45 min | Medium-Hard |
| 05 | Cross-Region Replication Architecture | Integration | 45 min | Hard |

## How to Use These Exercises

1. Start with Exercise 01 and work through them in order.
2. Attempt each exercise before looking at the corresponding solution.
3. Use the hints only when stuck -- they are designed to guide, not give away the answer.
4. Check your work against the Success Criteria before moving on.

## Prerequisites

- Completed Module 46 README
- PostgreSQL 14+ installed
- Docker and Docker Compose available
- Basic understanding of WAL (Write-Ahead Logging)
- Familiarity with Linux networking commands
