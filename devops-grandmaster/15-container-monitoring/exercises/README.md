# Module 15: Container Monitoring -- Exercises

These exercises build your skills in container observability from foundational concepts through production-grade monitoring strategies.

## Exercise Overview

| Exercise | Type | Topic | Difficulty |
|----------|------|-------|------------|
| 01 | Conceptual | Container resource metrics and cgroups | Beginner |
| 02 | Guided | Set up cAdvisor and Prometheus | Beginner-Intermediate |
| 03 | Independent | Grafana dashboards for container metrics | Intermediate |
| 04 | Challenge | Resource-based alerting and auto-scaling | Intermediate-Advanced |
| 05 | Integration | Monitoring strategy for production cluster | Advanced |

## How to Use These Exercises

1. Read the exercise file completely before starting.
2. Follow the instructions step by step.
3. Check your work against the success criteria.
4. Use hints only when you are genuinely stuck.
5. Compare your work with the corresponding solution in `../solutions/`.

## Prerequisites

- Docker and Docker Compose installed
- Basic familiarity with container resource limits (`--memory`, `--cpus`)
- A text editor for writing YAML and configuration files
- (Exercises 04-05) A running Docker environment with at least 2 CPUs and 4GB RAM
