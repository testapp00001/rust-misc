# Module 44: Dashboard Design -- Exercises

## Overview

These exercises build practical skills in dashboard hierarchy design, monitoring
methodology selection (Golden Signals, RED, USE), Grafana panel configuration,
and building dashboards that are useful during real incidents.

You will work with Prometheus queries, Grafana JSON models, and real-world
dashboard patterns drawn from production observability stacks.

## Prerequisites

- Familiarity with Prometheus (PromQL) basics
- Understanding of Grafana dashboard concepts (panels, variables, annotations)
- Completion of Module 43 (SLO Monitoring) is recommended
- Command-line comfort (bash)

## Exercises

| # | Title | Type | Focus |
|---|-------|------|-------|
| 01 | Golden Signals, RED, and USE Methods | Conceptual | Monitoring methodology selection and signal mapping |
| 02 | L1 Overview Dashboard in Grafana | Guided | Building a multi-service health overview |
| 03 | L2 Service Dashboard with Variables | Independent | Grafana variables, drill-down, RED method panels |
| 04 | Incident Response Dashboard | Challenge | Designing dashboards for active incident triage |
| 05 | Dashboard Hierarchy for Microservices | Integration | Full L1/L2/L3 system with linking and provisioning |

## How to Use These Exercises

1. Read the exercise file completely before starting.
2. Attempt the exercise without looking at the solution.
3. Check your work against the corresponding solution in `../solutions/`.
4. If stuck, use the hints -- but try first without them.
