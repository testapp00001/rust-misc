# Module 35: Helm Charts -- Exercises

## Overview

These exercises build your Helm skills from foundational chart structure
through to production-grade deployment pipelines. Complete them in order;
each one builds on concepts from the previous.

| Exercise | Difficulty | Focus |
|----------|------------|-------|
| 01 | Conceptual | Chart structure and templating fundamentals |
| 02 | Guided | Create a Helm chart for a web application |
| 03 | Independent | Environment-specific values files |
| 04 | Challenge | Helm library chart for shared templates |
| 05 | Integration | Helm-based deployment pipeline |

## Prerequisites

- Helm 3.x installed (`helm version`)
- A running Kubernetes cluster (minikube, kind, or cloud)
- `kubectl` configured and working
- Basic familiarity with YAML and Kubernetes manifests

## Getting Started

```bash
cd exercises/
# Work through exercise-01.md first
```

Each exercise includes objectives, step-by-step instructions, success
criteria, and hints (hidden behind collapsible details tags).
