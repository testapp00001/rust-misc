# Module 73: Service Discovery -- Exercises

## Overview

These exercises cover Consul, etcd, DNS-based discovery, and client-side vs. server-side discovery patterns. Work through them after completing the [module lesson](../README.md).

## Exercise List

| # | Name | Type | Time | Difficulty |
|---|------|------|------|------------|
| 01 | Service Discovery Fundamentals | Conceptual | 15 min | Easy |
| 02 | Consul Service Registration | Guided | 30 min | Easy-Medium |
| 03 | etcd-Based Service Registry | Independent | 40 min | Medium |
| 04 | Client-Side vs. Server-Side Discovery | Challenge | 45 min | Medium-Hard |
| 05 | Multi-Datacenter Discovery Architecture | Integration | 60 min | Hard |

## How to Use These Exercises

1. Read the module lesson (README.md) first.
2. Start with Exercise 01 to verify conceptual understanding.
3. Work through exercises in order -- each builds on the previous.
4. Attempt each exercise before looking at the hints.
5. Check your work against the solutions only after completing an exercise.

## Prerequisites

- Understanding of DNS, HTTP APIs, and basic networking
- Familiarity with JSON and key-value stores
- (For exercises 02-05) Consul and/or etcd installed, or access to documentation
- Python 3.x for code-based exercises
