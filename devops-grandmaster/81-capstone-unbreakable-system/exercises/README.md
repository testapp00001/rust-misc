# Module 81: Capstone - The Unbreakable System - Exercises

This capstone module brings together every concept from the entire DevOps
Grandmaster curriculum. You will design, build, and validate a production
system that survives failures, scales under load, heals itself, and recovers
from disaster.

## Exercise List

| Exercise | Title | Type | Time | Difficulty |
|----------|-------|------|------|------------|
| 01 | Architect the Unbreakable System | Conceptual | 30 min | Medium |
| 02 | Core Infrastructure with Kubernetes | Guided | 45 min | Hard |
| 03 | Observability Stack | Independent | 45 min | Hard |
| 04 | Disaster Recovery and Chaos Testing | Challenge | 45 min | Hard |
| 05 | Full System Deployment | Integration | 60 min | Expert |

## Prerequisites

Before starting these exercises, you should have completed the preceding
modules covering:

- Containers and Docker (Modules 01-10)
- Monitoring and logging (Modules 11, 15)
- CI/CD pipelines (Module 16)
- Scaling and load balancing (Modules 18-20)
- Kubernetes fundamentals
- Networking and security

## How to Use These Exercises

1. **Attempt each exercise independently first.** The hints exist for when
   you are genuinely stuck, not as a first resort.
2. **Write actual code and manifests.** Architecture diagrams on paper are
   not enough -- you must produce deployable artifacts.
3. **Test your work.** Every exercise has measurable success criteria.
   If you cannot verify it works, you have not finished.
4. **Compare with the solution only after attempting the exercise.** The
   solutions exist to fill gaps in your understanding, not to replace it.
