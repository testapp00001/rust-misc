# Module 39: Metrics Collection -- Exercises

## Overview

These exercises cover metrics collection with Prometheus, Grafana, PromQL,
exporters, and alerting rules. Each exercise builds on the previous one so
complete them in order.

## Prerequisites

- Docker and Docker Compose installed
- A web browser for Grafana and Prometheus UIs
- Basic familiarity with YAML and HTTP
- `curl` or any HTTP client for generating traffic

## Exercise List

| # | Title | Type | Estimated Time |
|---|-------|------|----------------|
| 01 | Metric Types: Counter, Gauge, Histogram, Summary | Conceptual | 20 min |
| 02 | Set Up Prometheus and Grafana with node_exporter | Guided | 35 min |
| 03 | Write PromQL Queries for Common Scenarios | Independent | 40 min |
| 04 | Instrument an Application with Custom Metrics | Challenge | 45 min |
| 05 | Design a Metrics Strategy for Microservices | Integration | 60 min |

## How to Use

1. Read the exercise markdown file.
2. Follow the instructions and write your answers, queries, or manifests.
3. Run the hands-on steps in your local environment.
4. Check your work against the success criteria.
5. Compare with the solutions only after attempting the exercise yourself.
