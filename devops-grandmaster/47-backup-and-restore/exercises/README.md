# Module 47: Backup & Restore -- Exercises

These exercises build your ability to design, implement, and validate database backup and restore strategies. You will work through backup selection, automation, point-in-time recovery, and integrity verification.

## Exercise List

| # | Name | Type | Time | Difficulty |
|---|------|------|------|------------|
| 01 | Backup Strategy Selection | Conceptual | 15 min | Easy |
| 02 | Automated Backup Pipeline Setup | Guided | 30 min | Easy-Medium |
| 03 | Point-in-Time Recovery Execution | Independent | 30 min | Medium |
| 04 | Backup Verification and Integrity Testing | Challenge | 45 min | Medium-Hard |
| 05 | Complete Backup and DR Plan | Integration | 45 min | Hard |

## How to Use These Exercises

1. Start with Exercise 01 and work through them in order.
2. Attempt each exercise before looking at the corresponding solution.
3. Use the hints only when stuck -- they are designed to guide, not give away the answer.
4. Check your work against the Success Criteria before moving on.

## Prerequisites

- Completed Module 47 README
- PostgreSQL 14+ installed
- AWS CLI configured (for S3 storage exercises)
- Basic bash scripting proficiency
- Understanding of WAL archiving
