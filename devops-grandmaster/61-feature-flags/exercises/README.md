# Module 61: Feature Flags - Exercises

Welcome to the Feature Flags module exercises. These five exercises will take you from understanding the conceptual foundations of feature flags to integrating them into a full CI/CD pipeline.

## Exercise Overview

| Exercise | Title | Type | Difficulty |
|----------|-------|------|------------|
| 01 | Feature Flags and Deployment vs Release | Conceptual | Beginner |
| 02 | Implement Feature Flags in an Application | Guided | Beginner-Intermediate |
| 03 | Gradual Rollout with Feature Flags | Independent | Intermediate |
| 04 | Feature Flag Management System | Challenge | Intermediate-Advanced |
| 05 | Feature Flags in CI/CD Pipeline | Integration | Advanced |

## Prerequisites

- Basic understanding of software deployment concepts
- Familiarity with at least one programming language
- Understanding of configuration management
- Basic knowledge of CI/CD pipelines

## How to Use These Exercises

1. Work through exercises in order -- each builds on the previous one.
2. Attempt each exercise before looking at the hints.
3. Check your work against the success criteria before moving on.
4. Solutions are available in the `solutions/` directory, but try first without them.
