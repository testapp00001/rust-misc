# Module 25: Kubernetes Architecture -- Exercises

## Overview

These exercises reinforce the core concepts from [Module 25: Kubernetes Architecture](../README.md).
Complete them in order -- each builds on the previous one.

## Exercise List

| # | Name | Type | Time | Difficulty |
|---|------|------|------|------------|
| 01 | Map the Kubernetes Architecture | Conceptual | 20 min | Easy |
| 02 | Inspect the Control Plane | Guided | 30 min | Easy-Medium |
| 03 | Trace a Pod Creation Request | Independent | 40 min | Medium |
| 04 | Diagnose a Broken Cluster | Challenge | 45 min | Medium-Hard |
| 05 | Design a Highly Available Control Plane | Integration | 45 min | Hard |

## How to Use These Exercises

1. Read the exercise file completely before starting.
2. Try to solve it without looking at hints first.
3. Use the `<details>` hint sections only if you are stuck.
4. After completing an exercise, check your answer against the solution.
5. If your answer differs from the solution, that is fine -- understand *why* both approaches work.

## Prerequisites

- You have read the [Module 25 README](../README.md).
- You have a text editor or terminal available.
- Exercises 02, 03, and 04 require a running Kubernetes cluster (kind, minikube, or k3s).
  See the README for setup instructions if you do not have one yet.
