# Module 71: Performance Tuning -- Solutions

## Overview
This directory contains reference solutions for the [Module 71 exercises](../exercises/).
Each solution includes the complete answer, an explanation of *why* it works, and
common mistakes to avoid.

Read the solution only after attempting the exercise yourself. If your answer differs
from the solution, that is fine -- understand *why* both approaches work.

## Solution List
| # | Exercise | Key Concepts |
|---|----------|--------------|
| 01 | [Kernel Parameter Analysis](solution-01.md) | sysctl defaults, failure modes, optimized values |
| 02 | [sysctl Tuning for High Throughput](solution-02.md) | sysctl.conf, apply/verify, benchmark impact |
| 03 | [File Descriptor and Connection Limits](solution-03.md) | ulimit, limits.conf, systemd, container limits |
| 04 | [Network Stack Optimization](solution-04.md) | TCP Fast Open, BBR, buffer sizes, iperf3 |
| 05 | [Full System Performance Playbook](solution-05.md) | Ansible, validation, monitoring, rollback |

## How to Use These Solutions
1. Attempt the exercise first.
2. Compare your answer to the solution.
3. Read the "Why This Works" section to understand the reasoning.
4. Read the "Common Mistakes" section to avoid pitfalls.
5. If your approach differs, evaluate both -- there is often more than one valid way.
