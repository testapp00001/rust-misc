# Module 71: Performance Tuning -- Exercises

## Overview
These exercises reinforce the core concepts from [Module 71: Performance Tuning](../README.md).
Complete them in order -- each builds on the previous one.

## Exercise List
| # | Name | Type | Time | Difficulty |
|---|------|------|------|------------|
| 01 | Kernel Parameter Analysis | Conceptual | 15 min | Easy |
| 02 | sysctl Tuning for High Throughput | Guided | 30 min | Easy-Medium |
| 03 | File Descriptor and Connection Limits | Independent | 30 min | Medium |
| 04 | Network Stack Optimization | Challenge | 45 min | Medium-Hard |
| 05 | Full System Performance Playbook | Integration | 45 min | Hard |

## How to Use These Exercises
1. Read the exercise file completely before starting.
2. Try to solve it without looking at hints first.
3. Use the `<details>` hint sections only if you are stuck.
4. After completing an exercise, check your answer against the solution.
5. If your answer differs from the solution, that is fine -- understand *why* both approaches work.

## Prerequisites
- You have read the [Module 71 README](../README.md).
- You have root/sudo access to a Linux system (or a VM/container).
- You are familiar with the Linux command line.
- You understand basic networking concepts (TCP, sockets, connections).
