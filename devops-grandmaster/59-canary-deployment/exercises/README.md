# Module 59: Canary Deployment -- Exercises

## Overview

These exercises reinforce the core concepts from [Module 59: Canary Deployment](../README.md).
Complete them in order -- each builds on the previous one.

## Exercise List

| # | Name | Type | Time | Difficulty |
|---|------|------|------|------------|
| 01 | Canary vs Blue-Green Analysis | Conceptual | 15 min | Easy |
| 02 | Build a Canary with Argo Rollouts | Guided | 30 min | Easy-Medium |
| 03 | Design Metric-Based Canary Analysis | Independent | 30 min | Medium |
| 04 | Canary with Header-Based Routing | Challenge | 45 min | Medium-Hard |
| 05 | Full Canary Pipeline with Automated Rollback | Integration | 45 min | Hard |

## How to Use These Exercises

1. Read the exercise file completely before starting.
2. Try to solve it without looking at hints first.
3. Use the `<details>` hint sections only if you are stuck.
4. After completing an exercise, check your answer against the solution.
5. If your answer differs from the solution, that is fine -- understand *why* both approaches work.

## Prerequisites

- You have read the [Module 59 README](../README.md).
- You have a text editor or terminal available.
- Basic understanding of Kubernetes, Istio, and Prometheus concepts.
- Familiarity with [Module 58: Blue-Green Deployment](../58-blue-green-deployment/README.md) is recommended.
