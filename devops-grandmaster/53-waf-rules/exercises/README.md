# Module 53: WAF Rules -- Exercises

## Overview

These exercises build your ability to design and implement Web Application Firewall rules that defend against the OWASP Top 3 web attacks: SQL injection, Cross-Site Scripting (XSS), and Cross-Site Request Forgery (CSRF). You will progress from analyzing attack payloads to writing production-grade WAF configurations.

## Exercise List

| # | Name | Type | Time | Difficulty |
|---|------|------|------|------------|
| 01 | Attack Payload Recognition | Conceptual | 15 min | Easy |
| 02 | SQL Injection WAF Rules | Guided | 30 min | Easy-Medium |
| 03 | XSS Protection Rules | Independent | 30 min | Medium |
| 04 | CSRF Token Validation | Challenge | 45 min | Medium-Hard |
| 05 | Comprehensive WAF Policy Design | Integration | 45 min | Hard |

## Getting Started

Work through the exercises in order. Each exercise builds on concepts from the previous one. Solutions are available in the `../solutions/` directory, but attempt each exercise before reviewing the solution.

## Prerequisites

- Basic understanding of HTTP request structure (headers, body, query parameters)
- Familiarity with SQL syntax (SELECT, WHERE, UNION, comments)
- Basic knowledge of HTML and JavaScript
- Access to a text editor for writing WAF rule configurations
- Optional: AWS account with WAF v2 access, or a local ModSecurity/Coraza instance for testing
