## Blameless Culture
```
Focus on systems, not individuals
Ask "how did the system allow this?" not "who did this?"
Goal: learn and improve, not assign blame
```

## Root Cause Analysis
```
5 Whys: Keep asking "why" until root cause
Fishbone diagram: Categorize causes
Timeline analysis: What happened when
```
